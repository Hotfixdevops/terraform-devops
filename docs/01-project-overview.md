# Stage 01 — Project Overview

## Objective

This project is an enterprise-style AWS infrastructure project built using Terraform.

The goal is to demonstrate Infrastructure as Code, modular Terraform design, AWS networking, security, compute, and DevOps practices.

## Technology Stack

- AWS
- Terraform
- Git
- GitHub
- Linux

## Architecture Roadmap

The infrastructure will be developed incrementally:

1. Project foundation
2. VPC networking
3. Security groups
4. EC2 compute
5. IAM
6. Load balancing
7. Auto Scaling
8. Application layer
9. Database layer
10. Monitoring and logging
11. CI/CD
12. Security hardening
13. Final validation

## Implementation Principle

Each infrastructure stage will be implemented, validated, documented, and committed separately.

No infrastructure should be applied blindly. Terraform plans must be reviewed before applying changes.
